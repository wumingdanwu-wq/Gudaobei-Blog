## 起因

我想给自己的咖啡店私域群做点数据复盘：谁爱互动、谁长期潜水、顾客到底在聊咖啡、小火锅还是活动。靠手翻聊天记录太累，所以我决定在自己的电脑上搭一个本地分析工具。

先说明几个前提：这个群是我自己有权管理的咖啡店群，所有数据只在本地处理，不上传。我也不打算做全天候监听，只想在需要复盘或策划活动时，手动跑一次。

## 工具清单

我这次用到的东西不多：

- **微信电脑版 4.1.15.56**：已登录，它是本地聊天数据的来源。
- **wechatauto-replica 1.2.8.1**：GitHub 开源项目，负责读取本地微信数据库、查询历史消息、监听和导出等基础能力。
- **Python 3.12.10（64 位）**：用来跑项目和写我自己的分析程序。
- **PowerShell + Git 2.55.0**：下载源码、装依赖、启动和测试。

## 安装过程

这次是在新电脑上重新部署，没有沿用旧电脑的虚拟环境。整个流程我一步步走下来，每一步都确认过结果：

1. 检查微信电脑版：已登录，能检测到微信进程。
2. 检查 Python 和 Git：都已安装。
3. 下载 GitHub 源码：成功。
4. 创建独立的 `.venv` 虚拟环境：成功。
5. 安装项目依赖：成功。
6. 测试命令行入口：通过。
7. 连接本地微信数据库：初始化成功，发现 20 个数据库文件。
8. 精确查找目标群：成功匹配。
9. 导出群成员名单：成功导出 116 名成员。

项目放在 `D:\WeChatSchoolAssistant`，虚拟环境在它下面的 `.venv`。需要留意的一点是，程序里用的"微信账号目录"只是本地数据目录的标识，并不等于我的实际微信号，别混淆。

## 目前真正跑通的部分

到这一步，我拿到的成果是：环境装好了，数据库能初始化，目标群能精确匹配，116 人的成员名单导出成了 CSV，用 Excel 就能打开。

但我得老实说，这只证明了"安装、初始化、找群、导名单"成功，**历史消息分析还没做完**。别被"名单导出成功"带偏，以为整个项目已经完工。

## 我最终想要的东西

我要的不是"接管微信"，也不是盯着所有聊天，而是一个服务咖啡店私域客户的本地运营分析工具，包含五个功能：

1. **手动读取历史消息**：选定群，点按钮，读取指定时间范围的聊天记录，不用为此一直开着监听器。
2. **客户发言统计**：每人发言次数、每日活跃度、活跃时段，找出爱互动的客户和长期沉默的成员。
3. **聊天内容总结**：提炼顾客对咖啡、饮品、小火锅、店铺活动和服务的反馈，整理他们的问题和潜在消费需求。
4. **推荐聊天文案**：按真实聊天场景生成不同风格的回复，比如亲切回应、新品推荐、活动邀约、沉默客户维护。最后由我自己挑选、修改、发送，不是让程序代发。
5. **自动生成分析报告**：每次分析后，在桌面生成一份新的 HTML 报告和 CSV 统计表，方便保存，也方便对比不同日期的数据。

理想的使用流程很简单：打开微信登录，启动助手，点「读取历史消息并分析」，等它统计、总结、给出回复建议，最后桌面多出一份新报告。想复盘群聊、了解客户或策划推广时，手动跑一次就够了。实时监听不是主流程，它只能发现程序运行期间的新消息，替代不了微信自己的通知。

环境这块算折腾完了，接下来的重点是改程序，不是继续装东西。现在的「检查目标群」按钮只该负责确认群对不对；我要另外加一个按钮，真正去执行历史消息读取、统计分析和报告生成。

## 一点提醒

这类工具务必限定在自己有权管理的群里用。聊天内容、联系方式、消费偏好都属于需要妥善保管的客户信息，生成的报告我会存在本地受保护的目录里，不会公开上传。
