## 三、连接 VPS

Windows 打开 PowerShell：

```powershell
ssh root@你的VPS IP地址 -p 22
```

第一次连接：

输入：

    yes

然后输入 root 密码。

如果看到：

    #

表示登录成功。

------------------------------------------------------------------------

## 四、安装 S-UI 控制面板

执行安装脚本：

```bash
VERSION=1.3.10 && bash <(curl -Ls https://raw.githubusercontent.com/bulianglin/demo/main/s-ui-install.sh) $VERSION
```

安装完成后保存：

- 面板地址
- 用户名
- 密码

------------------------------------------------------------------------

## 五、基础配置流程

进入管理面板后：

1. 登录后台
2. 创建连接配置
3. 保存节点参数
4. 导出客户端配置

客户端导入后检查：

- 地址是否为 VPS IP
- 端口是否正确
- 延迟是否正常

------------------------------------------------------------------------

## 六、常用命令

登录：

```bash
ssh root@你的VPS IP地址 -p 22
```

修改密码：

```bash
passwd
```

清理 SSH 记录：

```bash
ssh-keygen -R 你的VPS IP地址
```

## 七、问题记录

### SSH 无法连接

检查：

- VPS 是否运行
- IP 是否正确
- 密码是否正确

### 节点无法使用

检查：

- 配置参数
- 服务状态
- 网络连通性
