## 目的与适用场景

我之前研究过银行卡境外消费、USDT 兑换汇率，发现只会"照着操作"心里很虚：钱到底去哪了？为什么扣的数不一样？所以这篇从头捋一遍：

**BTC 起源 → 虚拟资产 → 区块链 → 挖矿 → 钱包 → 交易 → USDT → 我的真实消费记录 → 风险**

全文尽量用**法币（人民币、美元）**做类比，方便理解。

## 一、从比特币开始：为什么会有 BTC

- **2008 年**，中本聪发表比特币白皮书；**2009 年**比特币网络上线。
- 它想解决的问题：**不依赖银行，也能在两个陌生人之间转移价值。**
- 类比：平时转账靠银行记账，"银行说你有 100 块，你就有 100 块"。比特币是把"记账权"交给全网的很多人，而不是某一家机构。
- **总量恒定 2100 万枚**，由程序规定。类比：法币央行可以多印钱，BTC 的"央行"是代码，不能多印。

## 二、什么是"虚拟资产"

虚拟币、加密货币、数字资产，日常基本指同一类东西。几个常见的区别：

| 名称 | 一句话理解 | 法币类比 |
| --- | --- | --- |
| BTC | 最早的去中心化数字资产，总量固定 | 更像"数字黄金" |
| ETH | 一个能跑程序的区块链平台上的币 | 更像"平台的燃料费" |
| USDT | 与美元挂钩的稳定币 | 更像"链上的美元" |

- **不能简单当股票**：股票背后是公司利润，很多币背后没有现金流，价格主要靠供需和市场情绪，所以波动很大。

## 三、区块链到底是什么

- **区块**：一页账本，记录一段时间内的若干笔交易。
- **链**：每一页都带着上一页的"指纹"，一页一页连起来。
- **分布式账本**：这本账不是只存在一家银行，而是全网很多节点各存一份。
- 一笔 BTC 转账大致经历：发起转账 → 广播给全网 → 矿工打包进区块 → 被后续区块层层确认。
- **为什么难篡改**：想改旧账，就得重算后面所有页，还要说服全网承认，成本极高。
- **和普通数据库的区别**：银行数据库是"一家说了算、能改"；区块链是"大家一起记、改不了"。

## 四、比特币是怎么"挖"出来的

- **挖矿**：矿工用算力竞争"记下一页账"的资格，抢到的人获得**区块奖励**。类比：像一场全球性的记账比赛，赢家拿工资。
- **工作量证明（PoW）**：矿工要做大量无意义的计算题，证明自己"确实花了力气"，这样作弊成本就很高。
- **减半**：奖励大约每四年（21 万个区块）减半一次，所以 BTC 发行越来越慢，直到 2100 万枚发完。类比：央行的印钞速度是预先写死、逐步降低的。
- **为什么普通电脑挖不到**：现在全网算力极大，需要专用矿机，普通电脑算力和电费都不划算。

## 五、钱包、地址和私钥

- **钱包地址**：类似银行卡号，可以告诉别人，用来收款。
- **私钥**：类似"银行卡密码 + 签名章"合在一起，谁有私钥，谁就能动这笔钱。
- **助记词**：私钥的一组好记的备份，等同于私钥。
- **币到底存在哪里？** 币其实一直在区块链账本上，钱包只是保管"能动这笔账的钥匙"。
- **丢了私钥怎么办？** 没有"客服"，没有"挂失重置"。类比：银行卡丢了可以找银行补办，私钥丢了没有任何机构能帮你找回。

## 六、交易所与链上转账

- **中心化交易所**：类似"银行 + 证券账户"。你在交易所里看到的余额，是**交易所记在它账本里的数字**，相当于你把钱存在它那里。
- **链上交易**：直接在区块链上转账，不经过交易所。
- **充币 / 提币**：往交易所转入叫充币；从交易所转出到自己的钱包叫提币。
- **网络 / 链**：同一种币可能跑在不同链上。类比：同样是"人民币"，银联、支付宝、微信各是不同通道，选错通道钱可能到不了账。
- **转错链**：地址格式看似没问题，但对方不支持那条链，资产可能永久丢失，转账前务必核对。

## 七、USDT：为什么它和 BTC 不太一样

- **稳定币**：设计目标是价格稳定，USDT 以 **1 USDT ≈ 1 USD** 为目标。
- USDT 由 Tether 公司发行，它声称有储备资产支撑。类比：像一种"链上的美元收据"，信任的是发行方。
- 为什么价格围绕 1 USD 小幅波动：市场供需 + 随时能兑换的预期会把价格拉回 1 美元附近。
- **BTC 与 USDT 的核心区别**：

| | BTC | USDT |
| --- | --- | --- |
| 价格 | 波动大 | 目标稳定在 1 USD |
| 发行 | 代码规定，无发行公司 | 公司发行 |
| 定位 | 数字资产 | 美元计价工具 |

- **USDT 有不同的链**（如 Tron、Ethereum 等），手续费和到账速度不同，转账时必须选对网络。

## 八、我实际遇到的 USD / USDT / 人民币兑换问题

整个流程可以画成一条线：

```text
人民币 → 银行卡/境外消费 → USD → USDT → 实际支付
```

每一步都可能有"损耗"：

1. **人民币 → USD**：银行按自己的汇率换算，通常和中间价有点差距。
2. **境外交易手续费**：银行卡可能收一道外币交易手续费。
3. **USD → USDT**：兑换价格不一定恰好是 1:1，会有点差。
4. **USDT 兑换/转账手续费**：平台或链上可能还会收一笔。

所以**商品标价的 USD** 和**最终扣掉的 USDT** 一般不完全相等，差的部分就是汇率差 + 手续费。

### 看懂一笔交易：分两段算

**第一段：人民币买 USDT（含买入手续费）**

**第二段：USDT 付款**

- 商品标价（USD）：
- 实际扣除（USDT）：（如果手续费单独列出，要加上）
- **平台综合汇率 = 实际扣除 USDT ÷ 标价 USD**（单位：USDT/USD）

> 这一步已经包含了"当时 USDT 的汇率"和"平台手续费"，不需要再单独拆开。

**合并：这笔消费真正花了多少人民币**

1. 总人民币成本 = 实际扣除 USDT × 买入成本价
2. 折算汇率 = 总人民币成本 ÷ 标价 USD（单位：RMB/USD）
3. 对比基准 = 今天的 USD/CNY 汇率（人民币汇率直接取当前值即可）
4. **额外损耗 = (折算汇率 − 今天的 USD/CNY) ÷ 今天的 USD/CNY × 100%**

**示例（数字是假设的，只演示算法）**

| 项目 | 数值 |
| --- | --- |
| 标价 | 10 USD |
| 实际扣除 | 10.3 USDT |
| 买入成本价 | 7.20 RMB/USDT |
| 今天的 USD/CNY | 7.10 |
| 总人民币成本 | 10.3 × 7.20 = 74.16 RMB |
| 折算汇率 | 74.16 ÷ 10 = 7.416 RMB/USD |
| 额外损耗 | (7.416 − 7.10) ÷ 7.10 ≈ 4.45% |

这个 4.45% 里，一部分来自买 USDT 时的溢价和手续费，一部分来自 USDT 付款时的汇率和平台手续费，两段分别算，就能看出损耗主要出在哪一步。

## 九、BTC、USDT 与普通人到底有什么关系

- **BTC**：更像一种去中心化的数字资产，有人把它当长期持有的资产。
- **USDT**：更像数字资产世界里的"美元"，用来计价、结算、支付。
- 为什么实际支付里更常见 USDT：价格稳定，付款时不会因为币价涨跌多花或少花。
- 便利：跨境转账快，不依赖银行营业时间。风险：见下一节。

## 十、风险与我目前的认识

- **私钥 / 助记词安全**：不截图、不发给任何人，任何"客服"索要都是骗子。
- **诈骗与钓鱼网站**：认准官方网址，不点陌生链接。
- **假交易所 / 假平台**：谨慎对待"高收益、稳赚"。
- **转账不可逆**：转错、转丢，基本没有"撤回"。
- **汇率风险**：人民币、美元、USDT 之间的价格会变。
- **价格波动**：BTC 等资产短期波动可能很剧烈。
- **学习不等于投资**：我现在的目标是搞懂原理，不是追涨杀跌。
