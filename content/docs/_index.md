## 如何继续补充

每篇文档都是独立的 Markdown 文件，可直接编辑对应文件中的章节。填写完成后，删除“待编写”提示，并更新验证日期与目录状态。

新增文章时，在同一目录创建新的 Markdown 文件，设置标题、唯一的 slug 和排序 weight，再将链接添加到本目录。目录首页文件是 _index.md，以便 Hugo 将各篇文章生成独立页面。
