## 目的与适用场景

国内用户注册 Gmail 时常遇到三类问题：

- 提示“此电话号码无法用于验证”。
- 收不到验证码。
- 被要求用手机扫码并发送验证短信。

**原因分析：**

- 网络出口 IP被识别为中国大陆，或手机号注册次数过多。
- 物理设备已被谷歌风控系统识别（需要手机扫码发短信时）。
- 2025 年下半年起谷歌风控更严，网页端注册难度大，+86 手机号很难通过。
- 部分临时号码服务提供的虚拟号码被大量拉黑，即使注册成功也容易被秒封。

**核心思路**：准备“干净的设备”和“干净的网络环境”。

## 准备环境

**通用条件：**

- 网络：稳定的海外线路（日本、新加坡等），注册和养号期间不要频繁更换线路。
- 设备：没有频繁注册或登录过多个谷歌账号的设备。
- 辅助邮箱：QQ、163 等均可，用于找回账号。
- 出生日期：建议大于 18 岁（模拟器方案中建议填 20 岁左右）。

**按方案区分的准备：**

| 方案                      | 所需准备                                                                                              |
| ------------------------- | ----------------------------------------------------------------------------------------------------- |
| 方案一：手机端 Gmail App  | iPhone/iPad/安卓手机；iOS 在国区 App Store 下载“Gmail”，安卓在 Google Play 下载                       |
| 方案二：模拟器 + 全局模式 | 电脑安装安卓模拟器（雷电模拟器海外版或蓝叠模拟器国际版）；网络工具开启虚拟网卡模式并设为全局模式 |
| 方案三：修改浏览器语言    | 电脑端 Chrome 浏览器                                                                                  |

## 操作步骤

### 注册流程

**方案一：手机端 Gmail App（正规打法）**

1. 连接稳定的海外线路，打开 Gmail App。
2. 点击“添加其他账号” → 选择“Google” → “创建账号” → 选择“个人用途”。
3. 填写姓名、出生日期，选择系统推荐的邮箱地址或自定义前缀，设置密码。
4. 进入手机号页面时，在干净的手机环境下通常可以直接填写 +86 手机号并收到验证码。
5. 输入验证码，同意条款，注册完成。

**方案二：安卓模拟器 + 全局模式**

1. 在模拟器中打开 Chrome，选择“在不登录账号的情况下使用”。
2. 确认网络工具已开启虚拟网卡模式并全局生效，模拟器内所有流量走海外线路。
3. 搜索 gmail.com，点击“为个人创建账号”，填写姓名、出生日期并设置密码。
4. 验证手机号，有两种选择：
   - **使用自己的 +86 手机号（推荐）**：选择中国大陆 (+86)，填入号码接收验证码。若是主力账号，建议用自己的号码，因为之后异地登录的二次验证比较频繁。
   - **使用临时号码服务**：充值后选择 Google 服务，购买便宜地区的临时号码，在平台上收验证码；收不到则取消订单换号。**必须绑定辅助邮箱**，因为临时号码用完即废，日后只能靠辅助邮箱找回。

**方案三：修改浏览器语言跳过手机验证（网页端替补）**

1. 打开 Chrome“设置” → “语言”。
2. 删除所有中文（简体/繁体），添加“英语（美国）/ English (United States)”，并将其作为唯一语言。
3. 回到注册页面，刷新后按英文界面填写。
4. 到验证环节时，会变为填写辅助邮箱（Recovery email），且出现“跳过 (Skip)”按钮，点击跳过即可免手机号注册。

### 恢复邮箱

- 在“安全性与登录”中添加并验证辅助邮箱（QQ、163 均可），用于找回密码。
- 使用临时号码服务注册的账号必须绑定。

### 安全设置

1. **开启两步验证**：在安全设置中绑定“身份验证器 (Authenticator App)”。
2. **保存 2FA 密钥**：把页面上的两步验证密钥保存好，之后在电脑端登录时可直接用验证器生成的动态码。

### 新号养号“三大铁律”

1. **半个月内不要改密码**：新号或购买的成品号都一样，否则极易触发风控。
2. **半个月内不要频繁换设备/线路**：尽量只用固定的一台设备和固定线路。
3. **成品号首次电脑端登录用无痕模式**：登录后立即修改辅助邮箱和两步验证密钥，然后退出其他设备。

## 常用命令与配置

本流程无需命令行，关键配置项如下：

| 项目                   | 设置                                        |
| ---------------------- | ------------------------------------------- |
| 线路地区               | 日本、新加坡等，注册期间保持固定            |
| 网络模式（模拟器方案） | 虚拟网卡模式 + 全局模式                     |
| 模拟器                 | 雷电模拟器海外版 / 蓝叠模拟器国际版         |
| 手机号                 | 自己的 +86 号码（推荐）；或临时号码服务的号码 |
| 浏览器语言（方案三）   | 仅保留 English (United States)              |
| 辅助邮箱               | QQ / 163 等，需验证                         |
| 两步验证               | 身份验证器 (Authenticator App)，保存好密钥  |

## 检查结果

- 能成功创建账号并登录 Gmail 收发邮件。
- “安全性与登录”中辅助邮箱已验证，身份验证器已绑定，并已保存 2FA 密钥。
- 在固定设备和固定线路上连续使用半个月，没有被要求频繁验证或停用。

## 遇到的问题与解决办法

### 1. 提示“此电话号码无法用于验证”

- **原因**：IP 被识别为中国大陆，或该号码注册次数过多。
- **解决**：换用稳定的海外线路；改用手机端 Gmail App 注册；或使用方案三跳过手机验证。

### 2. 收不到验证码

- **原因**：线路或设备环境不干净，或临时号码服务的号码被拉黑。
- **解决**：检查全局模式是否生效；临时号码服务收不到验证码时取消订单换号（不扣费）；优先使用自己的 +86 号码。

### 3. 被要求用手机扫码发送短信

- **原因**：当前物理设备已被风控识别。
- **解决**：改用安卓模拟器 + 全局模式，使用全新的海外设备环境。

### 4. 注册成功后很快被停用或锁定

- **原因**：使用被拉黑的临时号码；未设置安全信息；过早修改密码或频繁切换设备、线路。
- **解决**：尽快绑定辅助邮箱和两步验证，按“三大铁律”养号。

### 两期视频观点有出入的地方

- 一期认为临时号码服务的号码基本被拉黑，另一期仍推荐在需要时使用。两者不矛盾，但临时号码方案成功率偏低、风险较高，建议优先用自己的 +86 号码。
- 方案三（改浏览器语言）为视频作者的说法，是否“100% 有效”需自行验证，谷歌策略可能随时调整。
